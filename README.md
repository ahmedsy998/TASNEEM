# تسنيم (TASNEEM) — استوديو صناعة الفيديو القرآني للأندرويد

تطبيق أندرويد أصلي (Native Android) مبني بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** لتصميم وإنتاج مقاطع الفيديو القرآنية الاحترافية بجودة عالية وبصيغة **MP4**.

---

## ١. الهوية البصرية ونظام الألوان المعتمد
يعتمد تطبيق **تسنيم** على هوية إسلامية عصرية فاخرة بالألوان المعتمدة:
- **البرتقالي الفاخر الأساسي (Primary Premium Orange):** `#E8872F`
- **الفضي الداكن (Dark Silver):** `#343A40`
- **الفحمي العميق (Deep Charcoal):** `#1D2227`
- **العاجي الناعم (Soft Ivory):** `#F5F1EA`
- **الرمادي الفضي (Silver Gray):** `#C5C8CB`
- **الأبيض الناصع (White):** `#FFFFFF`

يدعم التطبيق الواجهة العربية الكاملة بتخطيط من اليمين إلى اليسار (**RTL**) مع أوضاع الإضاءة (النهاري، الليلي، تلقائي حسب النظام) وسبعة أنماط خلفية لواجهة الاستخدام مستوحاة من الطابع الإسلامي.

---

## ٢. الميزات الأساسية المكتملة
1. **بيانات القرآن الكريم الكاملة (١١٤ سورة):**
   - الفهرس الكامل لجميع سور القرآن الكريم الـ ١١٤ بأسمائها العربية الصحيحة وعدد آياتها الدقيق ونوع تنزيلها (مكية/مدنية).
   - جلب النص القرآني بالرسم العثماني الموثق مع التفسير الميسر وترجمة المعاني دون أي تعديل أو إعادة صياغة للنص القرآني.
   - التحقق الدقيق من نطاق الآيات المختار (من الآية الأولى المختارة إلى الآية الأخيرة المختارة) وعرض إجمالي الآيات المحددة.
2. **تحميل صوت الآيات المختارة فقط (Selected-Verse-Only Audio Retrieval):**
   - يقوم نظام `AudioDownloadManager` بتحميل الملفات الصوتية المفردة الخاصة بالآيات المختارة فقط (`startVerse..endVerse`) بالترتيب القرآني الصحيح دون تحميل السورة كاملة أو الآيات غير المختارة.
   - التحقق من سلامة كل ملف صوتي واستخراج مدته الفعلية بالميلي ثانية عبر `MediaMetadataRetriever`.
3. **قائمة القراء العشرين المعتمدين (٢٠ قارئًا بالضبط):**
   - يحتوي التطبيق على القائمة المعتمدة المكونة من ٢٠ قارئًا شهيرًا بالأسماء العربية، مع إمكانية الاستماع لمعاينة صوتية وتبديل القارئ مع الحفاظ على نطاق الآيات المختار.
4. **مزامنة الصوت والنص القرآني:**
   - محرك مزامنة مبني على `AndroidX Media3 ExoPlayer` يحدد الآية النشطة أثناء التلاوة ويدعم التتبع على مستوى الكلمات عند توفر بيانات التوقيت الموثقة، أو على مستوى الآيات بدقة التلاوة الفعلية.
5. **مكتبة الخطوط العربية القرآنية (٨ خطوط):**
   - تشمل: الرسم العثماني المصحفي (`Amiri Quran / KFGQPC Uthmanic`)، `Amiri`، `Scheherazade New`، `Noto Naskh Arabic`، `Lateef`، `Noto Sans Arabic`، `Cairo`، و`IBM Plex Sans Arabic`.
6. **استيراد الخلفية من الهاتف مباشرة (بدون مكتبة خلفيات مسبقة):**
   - زران رئيسيان: **«اختيار صورة من الهاتف»** و**«اختيار فيديو من الهاتف»** عبر `Android Photo Picker`.
   - تحكم كامل بالاقتصاص، التكبير والتصغير، الموضع الأفقي والعمودي، السطوع، التعتيم، وتكرار فيديو الخلفية.
7. **البث الحي الثابت (Persistent Live Preview - البث الحي):**
   - لوحة معاينة حية ثابتة في أعلى شاشة المحرر تظل مرئية أثناء التمرير عبر الإعدادات السفلية وتنعكس فيها جميع التعديلات فورًا.
8. **علامة «تسنيم» المائية:**
   - توقيع عربي أنيق `تسنيم` قابل للسحب المباشر داخل شاشة البث الحي مع التحكم بالحجم، الشفافية، الهوامش، الظل، والتوهج، مع ضمان عدم حجب النص القرآني.
9. **تصدير الفيديو الكامل بصيغة MP4 فقط (MP4 Video Export & Validation):**
   - محرك رندرة أصلي (`MediaCodec` H.264/AVC + AAC + `MediaMuxer`) ينتج الفيديو كاملاً لكامل مدة التلاوة المختارة بدقة `1080p` أو `720p` وبأبعاد `9:16` أو `16:9` أو `1:1`.
   - فحص التحقق الكامل من الملف الناتج (وجود الملف، سلامة حاوية MP4، المسار المرئي، المسار الصوتي، ومطابقة المدة) وحفظه في `MediaStore` (`Movies/Tasneem`).

## ٣. المزودات الخارجية وتكوين المصادر الصوتية
- **النص القرآني العثماني:** يتم جلبه عبر `https://api.alquran.cloud/v1/ayah/{surah}:{ayah}/editions/quran-uthmani,ar.muyassar,en.sahih` و`https://api.quran.com/api/v4/quran/verses/uthmani` مع تخزين محلي دائم في ذاكرة التطبيق.
- **تلاوات الآيات المفردة:** يتم جلبها عبر محول `QuranAudioProviderAdapter` من `https://everyayah.com/data/{subfolder}/{SSSAAA}.mp3` و`https://api.alquran.cloud/v1/ayah/{surah}:{ayah}/{edition}`، وتوقيتات الكلمات الموثقة من `https://api.quran.com/api/v4/recitations/{id}/by_ayah/{surah}:{ayah}`.
- **إضافة مزودات إضافية:** يمكن تسجيل أي مزود إضافي للآيات المفردة عبر `ReciterRepository.registerAdditionalProvider(adapter)` للقراء الذين يتطلبون مصدر آيات مفردة خارجي (مثل القارئ بندر بليلة والقارئ إدريس أبكر).

## ٤. بناء ملف APK محليًا أو عبر GitHub Actions
### البناء المحلي:
```bash
gradle assembleDebug
```
يتم توليد ملف الـ APK في المسار:
`app/build/outputs/apk/debug/app-debug.apk`

### البناء التلقائي عبر GitHub Actions:
يوجد ملف سير العمل في `.github/workflows/build-apk.yml` ويقوم ببناء المشروع ورفع ملف `tasneem-debug-apk` كـ Artifact قابل للتحميل عند كل عملية دفع (Push) أو تشغيل يدوي (`workflow_dispatch`).
